# JUST A SIMPLE QUARTZ PREVIEWER HOSTED IN STREAMLIT

Information of the Themes are scrapped from [saberzero1's GitHub for Quartz Themes](https://github.com/saberzero1/quartz-themes).
Even so, this project is UNNOFICIAL and NOT AFFILIATED with Quartz nor [saberzol's](https://github.com/saberzero1/quartz-themes).
This is basically just catalogue implementation of the table in the README file provided by the original source code.
Therefore, please refer and go to the respective links for further information.

## How the code works

The code works with python libraries. Mainly, `urllib`'s `request` feature, and `streamlit`'s `iframe` widget. The information is accessed trough the open-source github repository. Only key matches with the table's column in the README file of the repo is parsed. The parsed value then be made to matches the link provided and inserted into iframe argument.
